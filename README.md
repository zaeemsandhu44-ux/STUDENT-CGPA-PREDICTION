# CGPA Predictor – Student Academic Performance

A Machine Learning-based CGPA Prediction System that predicts students' CGPA (0.0–4.0) using academic performance and lifestyle factors. The project uses Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Seaborn to preprocess data, analyze features, train regression models, and evaluate prediction accuracy.

**Key Features:**
- Predict student CGPA using academic and lifestyle data.
- Analyze assignment, midterm, and final exam marks.
- Include study hours, attendance, stress, anxiety, depression, sleep, and other relevant factors.
- Compare multiple regression models, including Linear Regression, Ridge, KNN, Decision Tree, Random Forest, and Gradient Boosting.
- Implement a manually weighted prediction model with a total weightage of 100%.
- Evaluate models using MAE, RMSE, R² Score, and overfitting gap.
- Visualize feature importance and actual versus predicted CGPA.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook.

**Project Goal:** To explore how academic performance and student lifestyle factors relate to CGPA and develop a data-driven prediction system.
